# Finance Workspace — Public Demo

공개 체험판: 채권관리, 외화관리(5개 화면), 건설중인자산, 비용증감 검토.

모든 회사·거래처·프로젝트·금액·환율·전표는 새로 생성한 가상 자료입니다.
운영 프로젝트의 원장, 보고서, 로그, 계좌, 사내 경로, 인증정보를 포함하지 않습니다.

## 범위

- 월 선택, 채권 검색·가상 전표 모달, 위험 현황, 회수 시나리오
- 외화잔액·평가·실현·Net 표, 환율·잔액 민감도
- 자산 대체 검토 상태, 내용연수별 정액법 상각 시나리오
- 비용 증감, 가상 검토 의견 작성 및 로컬 보고서 다운로드
- 선택 보드 요약 HTML, CSV 다운로드, 모의 갱신 진행률·로그

서버 로그인, 실제 SAP 실행, Excel 업로드·원본 계산 엔진, 공동 저장은 제공하지 않습니다.
이것은 원본 플랫폼의 전체 기능 이식본이 아닌 정적 체험판입니다.
실제 자료를 입력하지 마세요. 입력과 검토 상태는 페이지를 새로고침하면 사라집니다.
통신·분석 추적 스크립트·외부 CDN은 사용하지 않습니다. 호스팅 제공자의 일반 접속 로그는 별개입니다.

## GitHub Pages

이 폴더의 공개 파일만 별도 저장소에 업로드합니다. 운영 프로젝트 전체를 업로드하지 않습니다.
Settings → Pages → Deploy from a branch → main → /(root).
빌드·의존성 설치는 필요 없습니다. index.html, style.css, app.js, model.mjs, favicon.svg를 함께 게시합니다.

## 계산 단위

원화는 억원, 외화는 백만 USD입니다. 따라서 백만 USD × KRW/USD ÷ 100 = 억원입니다.
평가손익은 가상 장부환율 1,300원 대비 단순 잔액 평가입니다.
실현손익은 별도의 가상 시나리오이며 원장 추적값이 아닙니다.
Net = 평가손익 + 실현손익. 환율 시뮬레이션에서는 기실현 손익을 재평가하지 않습니다.
