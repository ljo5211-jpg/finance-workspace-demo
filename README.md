# Finance Workspace — 가상 체험판 v2

https://ljo5211-jpg.github.io/finance-workspace-demo/

원본 플랫폼의 화면·탐색·대시보드 템플릿을 재사용하고 새로 작성한 가상 자료를 적용한 공개 체험판입니다. 실제 회사 원장·Excel·DB·인증정보는 배포하지 않습니다. 실제 자료를 입력하지 마세요.

## 체험 범위

- 채권 운영/DEV, 외화 운영/DEV, 건설중인자산 대시보드
- 월·통화 필터, 상세 조회, 위험 분석, 환율·상각 시뮬레이션
- 자산 분류·내용연수 검토와 승인, 비용 증감 검토·확정
- 가상 검증 XLSX 및 선택한 대시보드의 독립 HTML 다운로드

## 정적 호스팅의 범위

GitHub Pages에서는 서버/Python 계산기를 실행하지 않습니다. 갱신은 미리 계산한 가상 산출물을 다시 확인하는 동작입니다. SAP 연결, 모델 API 호출, 실제 Excel 적재, 로그인, 팀별 권한과 공유 DB는 제공하지 않습니다. XLSX는 체험용 표 양식입니다.

작업 상태는 현재 브라우저에만 저장됩니다. 세션 종료로 체험 상태를 초기화할 수 있습니다. 완전한 운영 웹서비스가 아닌 기능 체험판입니다.

차트 라이브러리를 내장했으며 분석 추적 스크립트나 외부 데이터 API를 사용하지 않습니다. GitHub 호스팅의 접속 로그는 별개입니다.
